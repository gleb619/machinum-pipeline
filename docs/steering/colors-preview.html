m machinum / Folio

Palette proposal · light default · draft

Paper, ink, and
one quiet signal.

Folio is built for long sessions over long books: warm paper instead of white, ink instead of black, and a single verdigris accent for links and focus. Machine state — running, paused, failed — is the only thing allowed to raise its voice.

2 · Ramps

4 · Shadows

Generated by an SCSS function per theme: warm ink shadows in light, deep black in dark, plus a 1 px white inset for the lit edge. shadow-focus is the only ring used for keyboard focus.

5 · Same contract in the terminal

The TUI never uses truecolour: state is mapped to the nearest bright ANSI colour, dimensions are rules instead of shadows, and the label carries the meaning when NO_COLOR is set.

7 · Hosts

Web + TUI: Folio, as above. VS Code webview: the exception — colours follow --vscode-* so the panel matches the editor, and shadows collapse to borders. The class contract is identical; a bridge converts VS Code hex values to the RGB triplets Tailwind expects.

Light is the default theme; dark is opt-in via html[data-theme="dark"]. Full contract: colors.md · layout: layout.md. This page is a static draft — no build step, no external assets.
