# Tools

All tools operate on `Chapter`, `Paragraph`, or `Line`, with `ToolContext` (LLM, HTTP, vector store, OpenRouter, logger)
and `ToolContext`/`RunContext` (cache, target language, flags).  
Sorted by complexity (Low → High).
