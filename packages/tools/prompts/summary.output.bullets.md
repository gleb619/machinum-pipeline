## Output contract (bullet-list mode)

Output only a plain text bullet list:

- Each item must start with a dash (`-`) followed by a space.
- Each item must be on its own line.
- Do not add numbering, paragraphs, or additional formatting.
- Do not include any text outside of the list.
- Output exactly one bullet per fact, event, or important detail; cover every significant detail of
  the input.
