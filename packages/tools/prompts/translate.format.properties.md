## Input format (properties mode)

The text is organized into lines/paragraphs. Each line is provided as a `N=text` pair, where `N` is the 1-based line
number and `text` is the original {{sourceLang}} line (including TL notes, comments, formatting).

Translate the text of every pair from {{sourceLang}} to {{targetLang}}; the line number `N` is the identifier of the
line and must be kept unchanged.
